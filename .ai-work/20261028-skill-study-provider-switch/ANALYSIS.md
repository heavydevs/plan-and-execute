## External findings

- Reported delegation and effort experiments trade cost against accuracy; subagents were not a universal improvement over lower effort. Measurements depend on workload, model, cache and harness.
- The current guide distinguishes model generations and charges cache writes on GPT-5.6 and later; explicit stable-prefix breakpoints and retention have separate economics. A historical no-write-charge assumption is not portable.
- Effort availability is model-variant dependent, including conditional xhigh/max. The headless effort query is read-only; the invocation flag differs from a persistent interactive default.
- For the described enterprise setup, partner models use pay-as-you-go billing rather than pooled Gemini monthly tokens; first-party coordination can still consume first-party tokens. This does not establish identical accounting for individual plans.
- Headless output and budgets are documented; safe-mode disables customization rather than establishing a read-only security boundary. Native goals and sessions can add their own control loops.
- Current prompt-mode permission semantics differ from older combinations: prompt cannot be combined with auto, plan or yolo, and defaults to auto. Version-aware capability checks must prevent an implicit permission expansion.
- Paired resampling preserves the relationship between compared observations. The independent sampling unit must be defined before computing an interval.
- Unconsumed pipes can deadlock, communicate buffers output in memory, and timeout cleanup requires explicit process handling. Long-running output needs concurrent draining and bounded retention.
- A successful same-filesystem replacement has atomic rename semantics; this is not a transaction covering multiple files or a promise of durable persistence after power loss.
- Untrusted retrieved data and tool outputs must not be treated as instructions. Structured separation and least privilege are defense layers, not a guarantee of immunity.
- Vendor multi-model experiments can reduce both cost and pass rate; compare total cost per independently validated task against a simpler qualified baseline.
- Effort and alias capabilities vary by model, harness and installed CLI; unknown required capability excludes a candidate rather than widening permissions.
- API cache-write economics vary by generation and retention; subscription quota and cash cost must remain separate accounting units.
- Qwen safe-mode is not a sandbox; Kimi prompt-mode flag compatibility is version-specific.
- Whole-process cancellation and multi-file state publication need ownership and crash-recovery tests, not only atomic single-file writes.
- Fixture replay proves dispatch contracts, not empirical savings; repeated identical cases do not create independent benchmark samples.
