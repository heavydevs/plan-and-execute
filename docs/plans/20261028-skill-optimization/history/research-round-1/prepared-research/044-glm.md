## Implementation instructions

1. Persist normalized host, backend, endpoint profile name, actual model ID and quota-pool identity without secret values.
2. Make thinking/effort translation conditional on the supported GLM model and harness version. Unknown native controls must not be treated as a higher capability tier.
3. Keep workload qualification separate from generic tier mapping; do not inherit maximum Claude capability for a GLM profile.
4. Store API rates, subscription credit multipliers and cache economics in separate dated fields with null for unknowns. Refresh metadata without changing in-progress routes.
5. Inject configured environment references per child process and avoid editing the user's global Claude settings as an installation side effect.
