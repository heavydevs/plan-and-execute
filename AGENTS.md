# Plan-and-Execute — roteamento obrigatório de pesquisa até entrega

**Em qualquer pedido para pesquisar, planejar, implementar, revisar, testar, executar, retomar ou avançar uma task deste repositório, leia primeiro [`guia_de_pesquisa_execucao_tasks.md`](guia_de_pesquisa_execucao_tasks.md).** O guia escolhe a primeira task de desenvolvimento pendente a partir do manifest, não a primeira pesquisa pendente. Uma task só está encerrada quando pesquisa, arquitetura, implementação, testes, review independente requerido e gate de entrega estão comprovados.

**PRÓXIMO em uma NOVA conversa = executar somente a primeira task pendente até gate real ou bloqueio externo, e PARAR.** Leia [`PAE_ONE_TASK_CODESPACE_PROTOCOL.md`](docs/operations/PAE_ONE_TASK_CODESPACE_PROTOCOL.md), que define os papéis ChatGPT / Claude Opus 5.5 (revisor independente) / Sonnet via GitHub Actions + skill PAE (reparos e testes monitorados; sem Antigravity), limites de esforço e critérios de conclusão. Para a task 015, já em revisão, siga também o [handoff específico](.ai-work/chatgpt-executor/HANDOFF_REVISAO_015_NOVO_CHAT.md); não pule o parecer cego nem o gate original. Uma sessão implementadora ou corretora nunca valida independentemente seus próprios hashes. O link do Codespace NÃO concede acesso automático ao terminal ou Claude; usar só despachos/recibos realmente verificados.


**Regra de autorreparo:** qualquer teste, review, CI ou gate `failed`/`rejected`/`changes_requested` obriga **diagnosticar, corrigir e revalidar automaticamente a mesma task**, sem pedir confirmação e sem avançar. Reunir primeiro todas as falhas da bateria, corrigir com testes focais e repetir a validação integral. Diferenciar defeito reparável de falta de evidência/autorização externa; jamais fabricar recibo, revisor ou aprovação para fazer um gate passar. Ver [procedimento obrigatório no guia](guia_de_pesquisa_execucao_tasks.md#ciclo-obrigatório-de-autocorreção-após-reprovação) e [instruções do Projeto ChatGPT](.ai-work/chatgpt-executor/INSTRUCOES_PROJETO_CHATGPT.md).

Depois, leia [`.ai-work/chatgpt-executor/ENTRYPOINT.md`](.ai-work/chatgpt-executor/ENTRYPOINT.md), que encaminha para os documentos de execução, revisão, testes e evidências sob demanda. A versão de projeto ChatGPT dessas instruções está em [`.ai-work/chatgpt-executor/INSTRUCOES_PROJETO_CHATGPT.md`](.ai-work/chatgpt-executor/INSTRUCOES_PROJETO_CHATGPT.md).

Autoridade de execução: `.ai-work/20261028-skill-study-provider-switch/manifest.json` (não chats, Markdown ou pesquisa preparada). Preserve branch, dependências e escopo; jamais forje testes, logs, reviewers, sessões, recibos ou aprovação. A primeira task pendente é 015, com pesquisa já concluída. Nunca comece a 020 antes de concluir a 015 e as demais pendentes na ordem real do plano. Um commit/push é verificado no remoto por CAS, sem force-push. Revisão pelo próprio contexto ChatGPT **não** é independente.
